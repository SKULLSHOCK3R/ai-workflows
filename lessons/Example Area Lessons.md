# Example Area Lessons

Template for an area-specific lesson file. Copy it to `lessons/<Area> Lessons.md` (for example `lessons/Research Lessons.md`), delete this paragraph, and record lessons that apply only to that area. The coordinator names the file in a stage brief when the work touches that area; it is not preloaded at startup. Lessons that are also general tool rules stay in [lessons.md](../lessons.md).

Record one actionable lesson per line: `YYYY-MM-DD | Scope: task/project/area | concise actionable lesson`.

2026-10-13 | Scope: example | Replace this line with a real lesson: state the situation, the correction, and how to apply it next time.
