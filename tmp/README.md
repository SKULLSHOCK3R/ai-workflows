# tmp

Scratch space for intermediate files and tool output, for the task in progress only. Nothing permanent stays here: before a task ends, move anything worth keeping to its home (deliverables to `outputs/`, backups to `backups/`) and remove the rest. The launchers' stage briefs go in `tmp/stage-briefs/` and leave once the stage ends.

This folder's contents are ignored by Git (see `.gitignore`); only this README is tracked. Remove the matching rule from `.gitignore` if you want to track the contents.
