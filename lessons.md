# Lessons

Read with the shared [AGENTS.md](AGENTS.md) or [CLAUDE.md](CLAUDE.md) entry and [Project Startup.md](Project%20Startup.md) before each task, response, or delegated stage. Apply entries relevant to the current scope; the latest user request takes precedence. Area-specific lessons live in their own files under `lessons/` and are read only for that work (see [lessons/Example Area Lessons.md](lessons/Example%20Area%20Lessons.md)). Record each new lesson in the file for its scope (Maintenance in AGENTS.md).

Record one actionable lesson per line: `YYYY-MM-DD | Scope: task/project/general | concise actionable lesson`.

2026-10-13 | Scope: tools (Windows PowerShell 5.1 file writes) | Write text files with an explicit UTF-8 encoder (`[IO.File]::WriteAllText` with `New-Object System.Text.UTF8Encoding($false)`) and byte-compare against the source: the 5.1 defaults re-encode non-ASCII characters into garbage. Always pass absolute paths to `[IO.File]` methods, because .NET resolves relative paths against the process folder, not the `Set-Location` folder, so a failed read followed by a write can silently create an empty file somewhere else.
2026-10-13 | Scope: general (delegation briefs) | Recompute any expected totals in a stage brief from their component counts before handing off; a plan's group totals can contradict its own per-section counts.
2026-10-13 | Scope: tools (Claude Code setup) | New or changed files in `.claude/agents`, `.claude/skills` and hook entries in `.claude/settings.json` take effect only in a session started afterwards; run delegation tests in a fresh session after editing them.
2026-10-13 | Scope: tools (Claude Code hooks) | A Stop hook must exit 0 with no stdout (exit 2 or a block decision stops Claude finishing) and does not fire for subagents. Read `last_assistant_message` from the hook input and open the transcript only when that field is absent, because the transcript can lag.
2026-10-13 | Scope: tools (Claude Code hooks and rule loading) | Hook output added to context is capped at about 10,000 characters; longer output is saved to a file and only a short preview reaches the model, so a hook that dumps whole rule files silently drops most of them. Load core rule files through `@path` imports in CLAUDE.md instead (escape spaces with a backslash; quoted paths are not imported) and keep any hook's printed output well under the cap.
2026-10-13 | Scope: general (delegation, report files) | Subagents can be refused when they try to write report files. Brief them to return the report text, and have the coordinator save it with a UTF-8 encoder and byte-check it. If a stage is cut off, verify the baseline backup's hash, then have a fresh stage audit and finish the partial files rather than redoing them blindly.
2026-10-13 | Scope: general (Git with parallel sessions) | While another session has pending changes, commit with explicit paths (`git add -- <paths>`, then `git commit -- <paths>`), never `git add -A` or `-u` on broad folders, and check for `.git/index.lock` first. To stop tracking a file, run `git rm --cached <path>` and commit with no pathspec: a path-limited commit re-stages the file from disk and records an update instead of the removal.
2026-10-13 | Scope: general (web research) | Web-fetch summaries can invert table cells or invent quotations. Before relying on a permission, licensing, price or quoted value, re-fetch the page asking for verbatim text, or read the page text directly, and cite the checked wording.
