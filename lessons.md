# Lessons

Read with the shared [AGENTS.md](AGENTS.md) or [CLAUDE.md](CLAUDE.md) entry and [Project Startup.md](Project%20Startup.md) before each task, response, or delegated stage. Apply entries relevant to the current scope; the latest user request takes precedence. Area-specific lessons live in their own files under `lessons/` and are read only for that work (see [lessons/Example Area Lessons.md](lessons/Example%20Area%20Lessons.md)). Record each new lesson in the file for its scope (Maintenance in AGENTS.md).

Record one actionable lesson per line: `YYYY-MM-DD | Scope: task/project/general | concise actionable lesson`. Keep each line to about 400 bytes; longer detail goes to [Lesson Details.md](Lesson%20Details.md) and the lesson points there.

2026-10-13 | Scope: tools (Windows PowerShell 5.1 file writes) | Write text files with an explicit UTF-8 encoder (`[IO.File]::WriteAllText` with `New-Object System.Text.UTF8Encoding($false)`) and byte-compare against the source; pass absolute paths to `[IO.File]` methods. Details: [Lesson Details.md](Lesson%20Details.md).
2026-10-13 | Scope: general (delegation briefs) | Recompute any expected totals in a stage brief from their component counts before handing off; a plan's group totals can contradict its own per-section counts.
2026-10-13 | Scope: tools (Claude Code setup) | New or changed files in `.claude/agents`, `.claude/skills` and hook entries in `.claude/settings.json` take effect only in a session started afterwards; run delegation tests in a fresh session after editing them.
2026-10-13 | Scope: tools (Claude Code hooks) | A Stop hook must exit 0 with no stdout (exit 2 or a block decision stops Claude finishing) and does not fire for subagents. Read `last_assistant_message` from the hook input and open the transcript only when that field is absent, because the transcript can lag.
2026-10-13 | Scope: tools (Claude Code hooks and rule loading) | Hook output over about 10,000 characters reaches the model only as a short preview: load core rule files through `@path` imports in CLAUDE.md (escape spaces with a backslash) and keep hook output well under the cap. Details: [Lesson Details.md](Lesson%20Details.md).
2026-10-13 | Scope: general (delegation, report files) | Subagents can be refused when they try to write report files. Brief them to return the report text, and have the coordinator save it with a UTF-8 encoder and byte-check it. If a stage is cut off, verify the baseline backup's hash, then have a fresh stage audit and finish the partial files rather than redoing them blindly.
2026-10-13 | Scope: general (Git with parallel sessions) | While another session has pending changes, commit explicit paths only (`git add -- <paths>`, `git commit -- <paths>`) and check for `.git/index.lock`; untrack with `git rm --cached` and a pathspec-free commit. Details: [Lesson Details.md](Lesson%20Details.md).
2026-10-13 | Scope: general (web research) | Web-fetch summaries can invert table cells or invent quotations. Before relying on a permission, licensing, price or quoted value, re-fetch the page asking for verbatim text, or read the page text directly, and cite the checked wording.
2026-10-17 | Scope: tools (Claude Code permissions) | An `ask` rule and a hook answering ask can fail open in auto mode, so a risky call may run unprompted. Put anything an assistant must never do in `permissions.deny`, keep `ask` for the one class the user approves per task, and test each new rule with a harmless call in a fresh session.
2026-10-17 | Scope: tools (Claude Code settings) | Permission rules and hooks in the settings files are re-read into a running session when saved, but invalid-settings dialogs and unknown-tool warnings only appear in a fresh one; confirm a rule's tool name in a new chat. Bash and PowerShell rules match only the written command form, so treat them as defence in depth.
2026-10-17 | Scope: general (delegated image or file reading) | A reading stage that hit an image request limit reported pages that did not exist and the coordinator passed it on unchecked. Verify any stage's claim about images or files yourself (page count, render a page) before reporting it, and brief such stages to log every page with its printed number, mark unloaded pages not seen, and pause between batches.
2026-10-21 | Scope: tools (third-party agent CLIs) | An agent CLI run inside a Git repository can load that repository's AGENTS.md or GEMINI.md and follow its required reading, even for files outside its allow list. Start such a CLI from a scratch folder outside the project with no rule file in it or above it, add the project explicitly, and list every file the first run read.
2026-10-24 | Scope: tools (watching logs on Windows) | Git Bash `tail -F` on a log another process appends to can lock the file so the writer's append fails and the writer stops. Watch such logs by polling reads, and make long-running writers retry a failed log append.
2026-10-25 | Scope: tools (scheduled tasks) | Give a scheduled task one fixed script command with one exact allow rule. A prompt that lets each run phrase its own command never matches a saved "don't ask again" rule, so every run stops for approval and the rules pile up.
2026-11-02 | Scope: tools (agent CLI settings locks) | Deny rules can fail silently: in one CLI the file-read rules matched only with the drive letter and by prefix (a `/**` suffix matched nothing), and some tools could not be denied by settings at all. Prove every deny rule with a canary read of a file that does not exist, and check each run's tool list for the tools the settings cannot switch off.
2026-11-04 | Scope: tools (Windows paths in scripts) | Windows drops trailing dots and spaces from a path (`notes.md.` opens `notes.md`) and folds `..` segments, so a pattern check on the raw string can be bypassed. Canonicalise with `GetFullPath` first, re-derive the relative form, refuse anything not already in canonical form, and test folder prefixes with a trailing backslash.
2026-11-04 | Scope: tools (testing a lock on a headless assistant) | A model whose own instructions say "write nothing outside your folder" declines a test write, so the tool layer is never exercised and the test proves nothing. Test the lock with the identical command-line flags and a neutral prompt, and read the tool result in the stream, not the model's summary.
